# 本机视觉模板包格式

`vision-core` 从指定目录读取本机 PNG 模板，不进行网络访问。每张模板必须是 8 位 RGB 或 RGBA PNG，尺寸不超过 1024 × 1024。透明像素按白色背景合成。模板应从用户获准使用的目标界面中裁出牌面或按钮，保持相同的裁剪边界和皮肤，不要加入昵称、房间号等个人信息。原始截图与本机模板默认放在 Git 忽略的 `.local-test-data/` 内。

目录结构：

```text
template-pack/
  tiles/
    1m.png ... 9m.png 0m.png
    1p.png ... 9p.png 0p.png
    1s.png ... 9s.png 0s.png
    1z.png ... 7z.png
  actions/
    none.png
    chi.png
    pon.png
    kan.png
    riichi.png
```

`m`、`p`、`s` 分别代表万、筒、索；`z` 代表字牌；`0m`、`0p`、`0s` 为赤五。加载器要求 37 张牌图和 5 种按钮状态全部存在，避免缺少类别时误报。`none.png` 是无按钮状态的代表画面。识别返回每个候选的置信度和不确定槽位；任意槽位不确定时，整组手牌或按钮结果都不会作为确定结果提交。

当前仓库只含代码生成的合成测试图案，没有可分发的雀魂模板或模型。首次使用、浏览器缩放变化、不同皮肤和行动按钮的实际识别精度，须由本机真实截图测试确认。完整模板包的制作与授权仍是 v0.0.1 的未完成项。
