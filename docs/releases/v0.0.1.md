## 版本目标

本版本的详细产品目标见 [v0.0.1-product-spec.md](v0.0.1-product-spec.md)：在 Windows 10/11 x64 上提供可双击运行的雀魂网页版四人日麻辅助程序。程序只读截屏，识别手牌和行动按钮，在透明浮窗显示 Top-3 切牌、向听数、有效牌数、置信度，以及吃、碰、杠、立直建议。默认离线，不自动点击游戏、不注入网页、不上传截图。

行动识别新增无需 Python 的亮字输入和独立七类 Windows CPU 后端，使用原创几何/算术 fixture 验证；当前字体模型仍无法可靠覆盖全部按钮，尚未接入浮窗或打包，不能替代完整本机模板。详细结果和限制见[行动按钮开发记录](../action-recognition.md)。

此文件记录版本内任务、验收和行为变化；`docs/development-workflow.md` 记录跨版本的执行门禁。流程基线是本版本的首个任务，不代替产品功能验收。

## 范围与任务

1. **流程基线**：任务状态、版本测试、全项目回归、证据和门禁脚本。
2. **采集与校准**：窗口定位、只读局部截屏、首次框选、归一化坐标和 DPI 适配。
3. **视觉识别**：默认雀魂牌皮肤的手牌及行动按钮识别；低置信度与连续帧稳定性处理；本机真实截图验证。
4. **牌效核心**：普通形、七对子、国士向听；有效牌与可见牌扣除；Top-3 切牌。
5. **局面和行动**：摸切、吃、碰、杠、立直及不确定状态；动作前后比较与理由。
6. **浮窗集成**：置顶透明显示、拖动和缩放、暂停、隐藏、重新识别与手动纠错。
7. **便携发布**：自包含 Windows x64 包、启动和持续运行验证。
8. **公共牌集成**：同帧八区域采集、可见牌与指示牌统计、来牌和鸣牌后状态校对，记录为 V001-008。

防守危险度、完整打点估算、未来多回合搜索、三麻、多游戏和自动操作不属于本版本。

## 验收标准

- 新用户首次启动可完成牌桌区域校准，并在窗口移动、浏览器缩放与 Windows 100%、125%、150% DPI 下保持正确定位。
- 稳定画面可识别自己的手牌；牌数非法、遮挡、动画或识别低置信度时暂停确定性推荐并提示确认。
- 手牌变化后，浮窗显示 Top-3 切牌、向听、扣除可见牌后的有效牌数、置信度及简短理由。稳定画面到显示更新目标低于 250 ms。
- 吃、碰、杠、立直按钮出现时显示是否建议及动作前后牌效对比；用户自行在游戏中操作。
- 在没有 Python、Node、Rust 开发环境的干净 Windows 10/11 x64 系统上，解压便携包并双击可运行。默认不保存或上传原始截图。
- 每项功能拥有版本专用测试；全项目回归、打包冒烟和本机真实截图验收通过；任务状态只由门禁脚本写入 `succeed`。

## 行为变更记录

当前尚无已发布版本。以后任何旧行为的调整，必须在此记录旧行为、新行为和原因，并同步更新回归及兼容性测试。开发中修正：采集超时时不再用缓存画面递增帧号并推进三帧稳定判断；只有收到新的手牌或按钮画面才进行本轮识别，防止旧画面持续触发推荐。连续帧确认期间仍处理相同像素的独立采集帧；已有稳定结果且手牌和按钮区域像素均未变化时跳过识别。稳定画面仍会更新按钮状态，但相同手牌的 Top-3 结果改为复用；手牌、可见牌、宝牌指示牌、状态机手动修改、暂停或重新识别后重新计算。

公共牌接入后，配置格式从 1 升为 2，增加左、对、右三家副露区域。旧五区域文件加载时保留坐标并标记不完整，用户重新校准后才能启动自动识别；配置迁移和缺失区域拒绝启动由回归测试覆盖。采集改为一个会话捕获八个区域的外包矩形，再从同一帧裁出各区域，避免手牌、按钮和牌河时间错位。公共牌、宝牌和来牌变化也参与三帧稳定判断及缓存失效。

杠处理增加暗杠与加杠的牌效比较；补牌和新宝牌未知时明确显示“暂不建议”。固定面子数与暗杠数分开记录，暗杠后的门清手仍可立直。稳定画面证明手中四张移入杠子时可保留门清；重连时缺少暗杠背面证据则不推断门清。立直后的暗杠按[雀魂官方 FAQ](https://mahjongsoul.com/faq)检查本次摸牌及杠前后待牌种类、枚数；不额外禁止 FAQ 允许的面子分解变化。建议、手动确认及稳定公共牌观察采用同一个检查函数；断线、纠错或缺失摸牌帧时不猜测本次摸牌。规则边界与合成牌例见 [立直后暗杠检查](../riichi-kan-rules.md)。立直声明及暗杠背面的真实视觉确认仍未完成。

浮窗从只显示第一条动作理由改为列出每个可用动作的“建议 / 暂不建议”、前后向听及有效牌数，并单独显示信息不足的按钮；默认高度增至 410，状态名称改为中文。新增呈现测试并纳入版本与回归脚本；在本机合成布局中检查了四行行动与底部快捷键均完整显示。调试构建可用 `--layout-fixture` 重现该布局，发布构建不启用此入口。

浮窗增加“新局”按钮及 F7：清除上一局的立直、副露、可见牌、来牌、推荐缓存和手动输入，保留校准、模板、采集会话及暂停状态。“重识别”仍只用于当前局，保留立直与副露。自动换局目前只覆盖明确的稳定过渡：之前已经出现公共牌，随后全桌公共牌清空至一张指示牌、无副露或来牌、手牌为 13/14 张且至少两张移出、两张移入，并满足指示牌条件之一：首张改变，或原多张缩回一张。同一手牌、单次摸牌或摸切不足以判定换局。三帧确认后才执行，换局动画的拒识不会擦除上一份已接受的换局参考；新手牌和公共牌的合计非法时不得清除旧局。新旧单张指示牌恰好相同、未捕获清空阶段、和牌或流局字幕的情况仍待完整视觉实现，可用 F7 显式重置。本机合成浮窗已检查按钮、输入后重新计算、F7 清空和完整页脚布局；这不替代真实换局验收。
