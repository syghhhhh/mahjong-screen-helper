# 雀魂立直后暗杠检查

## 规则依据

2026-10-27 核对[雀魂官方 FAQ](https://mahjongsoul.com/faq)的“立直後の暗槓について教えてください。”条目。网页内容由官方 [`/api/faq/list`](https://mahjongsoul.com/api/faq/list) 提供：立直后不得改变待牌种类及枚数，不得送杠；除此之外的面子分解变化允许。此处采用雀魂规则，不采用部分竞技规则要求的“所有面子分解均不变”。

## 实现

`game-state/src/kan.rs` 的同一检查用于动作比较、`confirm_self_kan` 和 `observe_table`。需要满足：

- 已有固定面子全部是确认过的暗杠，仍为门清；固定面子少于四组。
- 连续观察到合法的手牌增加一张，确知本次摸牌；其种类与待杠四张一致。手牌排序不能代替摸牌证据。
- 去掉本次摸牌后处于听牌。分别枚举 34 种可能和牌，比较杠前和杠后的待牌种类，以及扣除自身手牌、既有暗杠后的物理可用枚数。
- 赤五与普通五按同一牌种计算，但确认时逐张验证实际持有的赤牌和普通牌。

对手弃牌导致的空听不改变杠的合法性，因此待牌枚举不按对手可见牌过滤。实际有效牌数仍扣除所有可见牌。合法不等于值得杠：补牌、新宝牌与打点尚未评估，浮窗继续显示保守比较及“暂不建议”。

断线、识别不确定、手动纠错会清除摸牌证据；只有随后重新观察到的摸牌才可用于立直后暗杠检查。确认立直后仍禁止吃、碰、明杠、加杠和自由切牌建议。

## 代表性合成测试

| 立直后的 13 张牌（牌码） | 本次摸牌 | 结果 |
| --- | --- | --- |
| `111234m 567p 23s 55z` | `1m` | 允许，仍待 `1s/4s` |
| `11123444m 56p 222s` | `1m` | 允许，仍待 `4p/7p`；面子分解减少不导致雀魂规则拒绝 |
| `1112345m 678p 678s` | `1m` | 拒绝，原待 `2m/3m/5m/6m` 缩为 `2m/5m` |
| `111123m 567p 23s 55z` | `9p` | 拒绝，待杠牌不是本次摸牌 |

状态测试还覆盖赤五、已有一组暗杠后的第二次暗杠、观察到非法杠后进入不确定状态，以及断线或纠错后不复用旧摸牌证据。运行时合成像素测试覆盖确认立直、摸牌、合法暗杠、公共牌更新和补牌，检查立直标志保留且不输出自由切牌建议。

这些测试不证明立直声明、杠按钮或暗杠背面在真实雀魂界面上已经可靠识别；这些视觉验收仍保留在版本任务中。
